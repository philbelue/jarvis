▸ Why This Works The mechanics behind it

Sonnet runs where reasoning actually matters — architecture, strategy, build decisions. Three channels.

Gemini Flash is perfectly capable of summarizing a brief, formatting a task, or posting a status ping. It's 20-30× cheaper per token.

requireMention: true stops Jarvis from reacting to webhook posts. Right now every n8n brief triggers a billable Sonnet call just because Jarvis sees the channel move.

Flipping the default model means any channel you forget to override won't silently cost Sonnet rates.

Hard Rules
Tape these to the wall
Rule 01
Never use Opus via API
Opus is Cowork-only (flat sub). API Opus is a $0 line item.
Rule 02
Sonnet = 3 channels, max
#thinking, #jarvis-strategy, #jarvis-builds. Everywhere else: Gemini or Mistral.
Rule 03
Webhook channels don't reply
requireMention: true on every brief channel. n8n posts shouldn't trigger billable calls.
Rule 04
No confidence without a test
"Config looks right" ≠ "it's working." Actually ping the bot. Actually see the response.
Rule 05
"Log it" ≠ "Ship it"
Log = write to agent-log.md. Ship = execute + test. Never conflate.
Rule 06
Daily cost report
Hermes posts MTD + delta-today to #arc-reactor at 11pm. Catch bleeds on day 2, not day 7.
Why $286 Happened
So you never diagnose this again
▸ Cause 1 · Default model was Sonnet

claude-sonnet-4-6 was set as the fallback in openclaw.json. Any channel without an explicit override silently inherited Sonnet — including chat, webhooks, and heartbeats.

▸ Cause 2 · Only 4 channels had overrides

Four automation channels were correctly routed to Gemini Flash. Everything else — the ten-plus channels you actually use — inherited the Sonnet default.

▸ Cause 3 · requireMention was false guild-wide

Every message in every un-overridden channel triggered a Sonnet call — including webhook posts, Hermes pings, and your own typing. The bot was reacting to everything.

▸ Cause 4 · Brief channels doubled the bleed

n8n posts a brief to #ixon-morning-brief (Gemini). Jarvis sees the message. Jarvis (on Sonnet default) generates a response. You pay twice — once for n8n, once for Jarvis reacting.

▸ Cause 5 · Heartbeats likely on Sonnet too

If the health-probe cron inherited the default model, that's a billable Sonnet call every 30 min, 24/7. Confirm in Claude Code — check the heartbeat_model key.

Notation Guide — Two Forms of the Same Shortcut

Every shortcut in this doc is written two ways:

  • Training-wheel form → Shift+⌘+3 — spelled out, plus-separated. This is how you read, type, and build muscle memory.
  • Compact form → ⇧⌘3 — Apple menus, Apple support docs, Reddit threads, and developer blogs all use this. Learn to read it so Apple's UI stops being hieroglyphics.

Modifier order (Apple convention — memorize this):

Control → Option → Shift → ⌘ → [Key]
Mnemonic: COSC-K. Command is always the last modifier before the key letter.
Example: Force Quit is Option+⌘+Esc ⌥⌘⎋, not "⌘+Option+Esc".

#2. Terminal + Bash — Mac Studio Daily Driver

Memory + Pressure

# Full memory pressure report (macOS verdict at bottom)
memory_pressure

# Top 10 processes by memory
ps aux | sort -rk 4 | head -10

# Top 10 by CPU
ps aux | sort -rk 3 | head -10

# Real-time memory view (q to quit)
top -o mem

# Real-time CPU view
top -o cpu

# Full system info
system_profiler SPHardwareDataType

Processes

# Find a process by name
ps aux | grep -i "openclaw" | grep -v grep

# Kill by PID
kill <PID>

# Force kill (⚠️ skips cleanup)
kill -9 <PID>

# Kill all matching a name (⚠️ test with pgrep first)
pkill -f "pattern"

# Preview what pkill would kill
pgrep -fl "pattern"

Network + Ports

# What's listening on port 18789 (OpenClaw health)
lsof -nP -iTCP:18789 -sTCP:LISTEN

# All established connections
lsof -nP -iTCP -sTCP:ESTABLISHED | head -20

# All open network connections
netstat -an | grep ESTABLISHED | head

# DNS lookup
dig example.com +short
nslookup example.com

# HTTP endpoint test (with status code)
curl -s -w "\nHTTP:%{http_code}\n" http://127.0.0.1:18789/health

# macOS built-in internet speed test
networkQuality

🔥 Launchd (macOS service manager)

# List user services (Jarvis services show here)
launchctl list | grep -i jarvis
launchctl list | grep -i hermes

# Restart a service (safe, launchd respawns)
launchctl kickstart -k gui/$(id -u)/com.jarvis.openclaw-gateway

# Get service info
launchctl print gui/$(id -u)/com.jarvis.openclaw-gateway

# Disable/Enable (⚠️ persists across reboots)
launchctl disable gui/$(id -u)/com.jarvis.openclaw-gateway
launchctl enable  gui/$(id -u)/com.jarvis.openclaw-gateway

# Where user-level service plists live
ls ~/Library/LaunchAgents/

Disk + Filesystem

# Disk space (human readable)
df -h

# Folder size (slow for big dirs)
du -sh ~/some/folder

# Find big files in a folder
du -ah ~/Downloads | sort -rh | head -20

# Disk info + SMART status
diskutil list
diskutil info /

# Flush filesystem caches (rarely needed)
sudo purge  # ⚠️ requires admin

Clipboard + Text

# Pipe command output to clipboard
cat file.txt | pbcopy

# Paste clipboard into command
pbpaste | wc -l

# Read clipboard
pbpaste

Handy One-Liners

# Say something out loud (good for build completion alerts)
say "Lane A shipped"

# Watch a log file live
tail -f /tmp/openclaw/openclaw-*.log

# Watch with grep filter
tail -f /tmp/openclaw/openclaw-*.log | grep -i "discord"

# Prevent sleep during long jobs
caffeinate -i <command>
caffeinate -t 3600  # stays awake 1 hour

# Battery + power
pmset -g batt
pmset -g

# Quick HTTP server on port 8000
python3 -m http.server 8000

Shell Quality of Life

# Open current folder in Finder
open .

# Open a file with default app
open file.pdf

# Open URL in default browser
open https://example.com

# Reveal file in Finder
open -R /path/to/file

# Show hidden files in Finder (toggle)
Shift+⌘+. (in Finder)

Permissions (reduce prompt fatigue)

  • /permissions shows the allowlist
  • Safe to auto-approve: Bash(grep:*), Bash(tail:*), Read(*), Glob(*), plugin-specific read-onlys
  • Keep prompting: Write, Edit, destructive Bash (rm, mv, chmod), git push
  • Rule: if worst case is "read wrong file," auto-approve. If worst case is "delete/modify/push," keep prompting.

Session + Context Hygiene

# Where CC sessions live on disk
ls ~/.claude/projects/

# Current project's sessions
ls ~/.claude/projects/-Users-philipbelue-jarvis-hq/
  • When context nears limit, /compact before auto-compact fires — you control the summarization prompt that way
  • /clear between unrelated tasks — don't let stale context pollute new work

#4. OpenClaw

Health

# Gateway health endpoint
curl -s http://127.0.0.1:18789/health

# Pretty-print JSON response
curl -s http://127.0.0.1:18789/health | python3 -m json.tool

Gateway Lifecycle

# 🔥 Restart (safe)
launchctl kickstart -k gui/$(id -u)/com.jarvis.openclaw-gateway

# Status
launchctl print gui/$(id -u)/com.jarvis.openclaw-gateway | head -30

# Find gateway PID
ps aux | grep "openclaw-gateway" | grep -v grep

# Force stop (⚠️ launchd will respawn unless disabled)
kill $(pgrep -f openclaw-gateway)

Logs

# Today's log (date-stamped)
tail -f /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log

# Last 100 lines
tail -n 100 /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log

# Filter by subsystem
grep '"subsystem":"gateway/channels/discord"' \
  /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | tail -20

# Errors only
grep -i error /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | tail

# All logs (rotated)
ls -lt /tmp/openclaw/ | head

Session Logs (DM + Channel History)

# Where agent sessions live
ls -lt ~/.openclaw/agents/main/sessions/ | head

# Read a session (jsonl, one record per line)
wc -l ~/.openclaw/agents/main/sessions/<uuid>.jsonl

# Pretty-print last N records (jsonl isn't valid JSON array)
tail -n 5 ~/.openclaw/agents/main/sessions/<uuid>.jsonl | \
  while read -r line; do echo "$line" | python3 -m json.tool; echo "---"; done

# Which model answered recent turns
grep -oE '"model":"[^"]+"' \
  ~/.openclaw/agents/main/sessions/<uuid>.jsonl | tail -20

Config

# Main config
ls -lh ~/.openclaw/openclaw.json

# Backups (automatic on every edit)
ls -lt ~/.openclaw/openclaw.json.bak.* | head

# Validate JSON before restart (always!)
python3 -c "import json; json.load(open('/Users/philipbelue/.openclaw/openclaw.json')); print('JSON valid')"

# Diff config against backup
diff ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak.5

# Backup manually before a risky edit
cp ~/.openclaw/openclaw.json \
  ~/.openclaw/openclaw.json.bak.manual.$(date +%Y%m%d-%H%M%S)

Workspace Files (System Prompt Composition)

# What Jarvis loads as system prompt
ls -lh ~/.openclaw/workspace/

# Word counts (keep MEMORY.md under 20k chars)
wc -c ~/.openclaw/workspace/*.md

# Grep across workspace
grep -l "protocol" ~/.openclaw/workspace/*.md

#7. Workflow Recipes (multi-tool combos)

Recipe: Post-Ship Verification

After Claude Code claims "shipped":

# 1. Gateway up?
curl -s http://127.0.0.1:18789/health

# 2. Config valid?
python3 -c "import json; json.load(open('/Users/philipbelue/.openclaw/openclaw.json')); print('valid')"

# 3. Service running?
launchctl print gui/$(id -u)/com.jarvis.openclaw-gateway | grep -E "state|pid"

# 4. Discord connected? (check log for "logged in")
grep -i "logged in" /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | tail -3

# 5. Which model answered the last DM?
grep -oE '"model":"[^"]+"' \
  ~/.openclaw/agents/main/sessions/<uuid>.jsonl | tail -5

Recipe: Full Stack Health Check

echo "=== LAUNCHD ==="
launchctl list | grep -iE "jarvis|hermes|openclaw"

echo "=== PROCESSES ==="
ps aux | grep -iE "openclaw|hermes|ollama" | grep -v grep | awk '{print $2, $11}'

echo "=== OPENCLAW HEALTH ==="
curl -s http://127.0.0.1:18789/health

echo "=== DISK ==="
df -h / | tail -1

echo "=== MEMORY ==="
memory_pressure | tail -1

echo "=== ERRORS TODAY (openclaw) ==="
grep -c "ERROR" /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log

echo "=== ERRORS TODAY (hermes) ==="
grep -c "ERROR" ~/.hermes/logs/gateway.log
Save this as ~/bin/jarvis-health and chmod +x it. Instant 10-second health snapshot.

Recipe: Restart The World (after Mac reboot)

# Usually launchd brings services back automatically. If not:
launchctl kickstart gui/$(id -u)/com.jarvis.openclaw-gateway
launchctl kickstart gui/$(id -u)/<hermes-label>

# Wait 15s, then health check
sleep 15 && curl -s http://127.0.0.1:18789/health

Recipe: Investigate a Bug (fast triage)

# 1. When did it start?
grep -n "symptom string" /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | head -5

# 2. Context ±20 lines
grep -B 20 -A 20 "symptom" /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | head -80

# 3. Nearby errors
grep -i -C 5 "error" /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | tail -40

# 4. Which model was in use?
grep -oE '"model":"[^"]+"' \
  ~/.openclaw/agents/main/sessions/<uuid>.jsonl | tail -10
